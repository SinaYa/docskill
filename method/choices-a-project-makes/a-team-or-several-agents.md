# A team, or several agents

| You found | What to settle | Who | What works |
|---|---|---|---|
| Other people's words already disagree with the user's | Name one owner whose words rule | Ask | *By hand*. A speaker on each quote, `Said by <name> on <date>`: *built* |
| It's someone else's project | Which parts of `AUTHORITY.md` belong here at all | Ask | `--leave-out`: *built*. Or don't adopt |
| Colleagues' words, or customer data in quotes | Trim it, or don't record | Ask | *By hand* |
| Agents running now | Who owns docs commits. The hook's `git add --all` sweeps up another agent's edits | Evidence if the docs say; else Ask | *By hand* |
| Agents working in worktrees | A new one has no `docs/` and no entry files. If docs are being moved, this belongs in that question | Evidence | *By hand* |
| Agents at once | One baton per stream, never delete another's, and claim a plan item before working on it | Evidence | *By hand* |
| How the project uses agents and models, or commits, in its docs or memory | Keep it, in `docs/rules/` | Evidence | *By hand* |
| An issue tracker | Whether it or `docs/plan/` holds the plan | Ask | *By hand* |
