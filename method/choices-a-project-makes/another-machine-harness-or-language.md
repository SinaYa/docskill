| You found | What to settle | Who | What works |
|---|---|---|---|
| Another platform | Skip `windows-tooling`. The link rule's snippet is PowerShell, so use `check-docs` | Evidence | *Built* |
| `docskill` not installed on this machine | No `refresh` until it is | Evidence | Install it from the README |
| Another harness | Its entry file, as a pointer. `@AGENTS.md` works only in one | Evidence, else Ask | *By hand* |
| No subagents | A self-check in place of the fresh-agent read | Evidence | *By hand* |
| Docs in another language | New docs in it. Fixed strings and the system's text stay English | Evidence | *By hand*; some checks assume English |
