# The runbook leads with the costliest decision and gives a whole worked command

- The highest-cost decision leads its section. Buried in a prose bullet, it was flagged by
  every test user of a round.
- Where a rule needs a command, the whole worked command is given there. Assembling one
  from four places cost turns.
- One sentence states the commonest flow outright, so nobody has to assemble it from
  several passages and prove it with a real command.
