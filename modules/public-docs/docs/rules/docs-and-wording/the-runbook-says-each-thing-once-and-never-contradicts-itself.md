# The runbook says each thing once and never contradicts itself

- A rule stated twice in near-identical wording sent a test user re-reading a long bullet
  for a distinction that did not exist.
- A headline rule that contradicted the runbook's own warning sent a test user into the
  trap the warning described.
- An absolute that drifts misleads: "there is no setup command" stayed after one existed.
  Check each absolute against the current tool.
