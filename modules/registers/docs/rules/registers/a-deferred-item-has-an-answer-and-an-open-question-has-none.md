# A deferred item has an answer, and an open question has none

- A **deferred item** is one somebody chose to postpone. It has an answer; the answer is *not
  now*.
- An **open question** has no answer. Nobody has decided, or no source records the decision.

Both are listed so that a gap is never mistaken for an oversight — and so that neither is
rediscovered as if it were new.

In `docs/project/deferred-and-open/`, one file per item. An open question only the user can answer
goes in [open decisions](../../project/open-decisions-for-the-user.md).

- A deferred item is stated as deferred wherever it is relevant, never omitted.
- An open question is recorded rather than answered by assumption.
- A question resolved after being recorded stays visible, with its resolution.
- Each deferred item has a reason, and none is waiting on information.
