# Deliberately unbuilt records the decision and the foundation to build on if revisited

Things this project has a foundation for and has **not** built, each with the decision
behind it and the foundation it must use if it is ever built.

**Nothing here is a roadmap.** Every entry is a decision that was taken to *not* do
something, usually for a reason that still holds. The point of the file is not to work
through it. It is that if one of these is ever revisited, it gets built on what already
exists rather than beside it — and that whoever revisits it knows why it was left alone,
so the decision gets remade on purpose instead of by accident.

In `docs/project/deliberately-unbuilt/`, one file per thing, named as the thing. Each says:
- **Built:** what exists.
- **Not built:** what was left alone.
- **Why not.** The decision and its reason.
- **If it is ever built, it must:** what it has to reuse.

Recurring reasons:
- **It has not been measured.** A default that is currently conservative should not become
  the default because it seems better.
- **The framework should be ready for a policy that does not exist.** Building the
  plumbing is cheap and reversible; inventing a reason to use them is
  neither.

**A known gap, deferred by the user until it causes a problem.** Recorded here rather than
as a task so it is findable when it bites instead of being rediscovered.
