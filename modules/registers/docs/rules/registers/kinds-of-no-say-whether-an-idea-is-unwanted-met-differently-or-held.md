# Kinds of no say whether an idea is unwanted, met differently, or held

Things raised during review, that the user decided must **not** shape the project's documentation. Kept so they are not raised again.

An entry is not always a verdict that the idea is bad. Each entry says which of three kinds it is:

- **No.** Not wanted.
- **Not this way.** The need may be real, but it will be met differently, or designed by the user when the time comes.
- **Held.** Kept aside for the user's review; it pushes the documentation neither way until then.

Entries go in `docs/rules/parked/`, one file per item, and are
[said once](../working-with-the-user/say-a-parked-or-rejected-item-once-and-never-re-raise-it.md):

- **Kind:**, **What:**, **Source:**, **Decided:** with the user's words, **Note:** where needed.
- **Raise again only if** a condition holds.
- An entry an autonomous run wrote says so: the AI's conclusions, not the user's decisions.
