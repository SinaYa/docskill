# A brief names the only accepted evidence and takes its baseline before the first edit

- How you prove it (the only accepted evidence): the brief names the check.
- Run it BEFORE your first edit. Take the baseline only once, before editing.
- After each item (or a small group of closely related ones), run the comparison.
- If anything differs, find the cause and fix it before moving on.
- A small difference: find out why and report it; don't hide it.
- At the end, where speed matters: the new version must not be slower than the baseline beyond noise; run it twice if the numbers wobble.
