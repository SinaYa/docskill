# What a run concludes alone is marked, and tagged apart from the user's words

- What applies the user's recorded words is written as decided, following how the docs already record decisions.
- **Everything else you conclude** — obvious derivations and researched answers alike — carries a mark in the documentation, as a blockquote note at the new or changed section. For example: **Accepted for lack of time, not endorsed; implications unexplored.**
- One mark per changed section, not per sentence.
- Never put the mark on the user's words.
- In the decision file, say for each point whether it is the user's words, *derived* (obvious) or *researched*.
