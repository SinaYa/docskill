# A new baton replaces the old one, and a new chat reads the latest

- The next baton makes the previous one unneeded, so it may be deleted. Carry over what still holds about
  how the user wants work done.
- A baton is named for its current situation, so the name tells which one is the latest.
- After a compaction or in a new chat, read the baton before answering. Never answer from what
  is left in memory.
- The baton may be deleted, so nothing a successor needs may live only there.
