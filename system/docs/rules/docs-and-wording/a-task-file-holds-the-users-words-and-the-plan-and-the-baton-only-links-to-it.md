# A task file holds the user's words and the plan, and the baton only links to it

A task is written down in a task file with the plan, the understanding of it,
and the exact things the user said; the baton links to that file and does not repeat what it
holds.

- Task files go in `docs/plan/`, listed in `docs/plan/order.md`.
- The user's words about the task stay in its task file, exact and dated as in
  `docs/user-quotes/`, and are not copied there too; the user's words about how work is done
  become a rule in `docs/rules/` if they last.
- In a task file the user's words come first, then the understanding, then the plan, each marked
  as whose it is.
