# Document only what this project alone can teach

- Skip anything a good developer or AI already knows. Document only what
  this project alone can teach: decisions, invariants, discoveries, traps.

**Only what is specific to us.** Do not explain what a competent developer or AI
already knows, and do not restate what the code says plainly. Document the
decisions, constraints and traps a reader could not infer: why a rule exists,
what breaks without it, which behaviour is deliberate.

**Written for a reader who has the code open.** Point at modules by path rather
than reproducing them. Code drifts; prose about intent does not.
