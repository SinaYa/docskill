# Record negatives with their numbers

- Record every negative result in `docs/handoff/`, so the next session does not retry it.
- Give the numbers, per case, not only the average.
- Say what machinery existed when it was tried. A negative describes that machinery, not
  the idea.
- A negative can be overturned. When a later attempt shows the limit was coverage or
  tooling rather than the idea, change the record and say why.
- Only a properly powered test earns a negative.
