# Standing rules go in `docs/rules/`, never in a handoff

- A handoff is rewritten by whoever picks the project up. A rule written only there
  survives one handoff.
- A standing rule goes in `docs/rules/`, and the user's words behind it in
  `docs/user-quotes/` when they are about the project.
- A handoff may point to a rule and holds the open items.
