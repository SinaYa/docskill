# Write state into the handoff as work lands

- When a measurement lands, a fix is made or a direction changes, write it into
  `docs/handoff/` right away, not at the end of the session.
- A session can end at any moment (context limit, usage limit, a crash). Assume the next
  one starts from the files alone.
- The baton is not a substitute: it may be deleted. Anything a successor needs goes into
  a handoff, a rule, the plan or the architecture.
