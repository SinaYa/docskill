# Read documentation several files at a time to save turns

- Every separate read costs a turn. Open as many files as the step needs at once:
  several reads in one message, or one command that prints several files.
- Choose the batch from the names first. Folder and file names are the table of
  contents, so the files a step needs can be picked before any is opened.
- Read a folder the reading order points to, such as `docs/user-quotes/` or
  `docs/handoff/`, in as few batches as its size allows.
- Read a single file on its own only when a batch pointed to it.
