# An audit re-reads against the user's exact words

When asked to audit persisted standards, re-read each against the user's own words in
`docs/user-quotes/` and look for:
- points they made that are missing;
- drift from what they said;
- contradictions between files;
- wording that can be read against their intent;
- the assistant's words inside theirs.

After writing any rule, run the same re-read on it.
