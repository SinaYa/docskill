# Ask only what only the user can answer

- Decide architecture yourself.
- Before asking, check whether the repo already decides it: `docs/rules/`,
  `docs/user-quotes/`, and `LIMITATIONS.md` where there is one. What the repo decides is not a question.
- Reserve questions for calls only the user can make: safety posture, spending their
  quota, anything irreversible.
- A decision listed in [open decisions](../../project/open-decisions-for-the-user.md) is
  never guessed. Leave it open and say so.
- Parked and rejected items are not questions:
  [say them once](say-a-parked-or-rejected-item-once-and-never-re-raise-it.md).
