# Fold a mid-task scope change in as a standing rule at once

- A user message may arrive mid-task and redefine scope ("make it an enforced
  requirement"). Treat it as a standing decision immediately.
- Record the rule in `docs/rules/`, and their words in `docs/user-quotes/` when they are
  about the project:
  [standing rules never go only in a handoff](../docs-and-wording/standing-rules-go-in-docs-rules-never-in-a-handoff.md).
- Apply it to the work in progress, not only to later work.
