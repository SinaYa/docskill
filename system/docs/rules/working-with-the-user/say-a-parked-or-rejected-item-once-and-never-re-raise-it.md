# Say a parked or rejected item once and never re-raise it

- A parked or rejected item is a deliberate decision, not an oversight.
- When it becomes relevant, say once that it was decided and where. Do not propose it
  again, and do not list it as open work.
- Parked items live in `docs/rules/parked/`, made when first needed. A rejected design alternative sits in
  the rule it lost to, marked *Rejected*.
- Only the user reopens one.
